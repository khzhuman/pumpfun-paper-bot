A slow-burn momentum paper-trading bot for make.fun's "Pump.fun Replay Sprint — Paper Bot, Real Ranking" bounty. It trades 10 SOL of paper money on a 24h replay of pump.fun bonding-curve activity: it waits for a curve to show sustained, broad-based buying pressure, buys a small first stake, pyramids only while the tape stays strong, and exits on a hard stop, a trailing stop, a fade in flow, a whale dump, or a time limit.

## Run it

```sh
node main.ts
```
